# KAJMAK — Balkan Steakhouse & Supper Club

Multi-page website for a fictional luxury Balkan steakhouse in New York City. Pages: menu, drinks, experience, VIP tables, private events, gallery (with lightbox), reservations and contact.

**Stack:** HTML, CSS, vanilla JavaScript

## Run locally

Asset paths are absolute under `/personal/kajmak/`. Serve the site from a web root (for example XAMPP's `htdocs/personal/kajmak`) so they resolve.
